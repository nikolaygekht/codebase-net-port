# Development steps

One folder per step, in order. The method is [`../DEV_APPROACH.md`](../DEV_APPROACH.md); this file is
just the index.

Start a step by copying the template:

```bash
cp -r claude/dev/_template claude/dev/001-step-name
```

**Every folder has its own number, and numbers are never reused.** An abandoned step keeps its folder
and gets a `SUMMARY.md` explaining why — that is a record, not clutter.

| [`009-performance-audit`](009-performance-audit/) | — *(audit)* | **done** 2026-08-27; audit half closed 2026-08-19 | The first measurement of anything in this port: 10 000 seeks over a 10 000-record table, run through the reference C library and through `CodeBase.Net`, against the same file and the same query sets — with matching per-record checksums proving both did identical work. **No change to `net/`.** Like-for-like the port is **1.36–1.43× the C's time per seek**, and it walks a tag **2.45× faster**, which removes suspect P4. The finding that reorders the rest: the C library's block cache — off unless `code4optStart` is called — is worth **14×**, far more than everything else on the suspect list combined, so **P1 dominates**. P2 confirmed and quantified at **~3 956 bytes allocated per seek**, though not attributed between the two candidates. P6 and P7 not exercised, and said so. **`ANALYSIS.md` then decomposed the 14×**: it is read syscalls at a measured 1.18–1.21 µs each and nothing else, against a hash-and-`memcpy` hit at 0.002 µs — and the same win is available here, **11.6× on a seek and 23.4× on a walk**, measured by giving the port a perfect cache. With I/O out of both sides the port's own CPU work is **1.4–1.7× the C's and 1.7× faster on a walk**, and the residual is P2: a fresh `byte[keyLength]` materialised for every comparison, worth 1.7–1.9× of the descent to remove. Also closed finding 6 (entries per leaf, and both leaf searches are linear), showed P7 changes nothing on unique keys, and carries a **retraction of its own first pass**, whose RAM-backed numbers never left tier-0 JIT. **Remediation designed, planned and executed 2026-08-21 to 2026-08-22** — eight sub-steps, the eighth unplanned. The cache decorates `IRandomAccessSource` rather than the index (a walk's reads are 96% DBF) and is **optional on the reference's own three-valued policy**, `Off`/`WhenExclusive`/`Always`, defaulting to the C's `OPT4EXCLUSIVE` — so today's default caches nothing and starts by itself when `LOCKING` arrives. Landed: compare-in-place, the padded comparison, `BlockResidency`/`BlockPool`, the cache itself, `Table.Refresh()`, the shared-cache lock and the concurrent-use detector, a benchmark project and a profiling driver. **The eighth sub-step is the one to read**: every gate had passed and the step was still wrong about where its time went for the third time — the answer was a `RandomAccess.GetLength` **per block read**, four per descent with the cache fully warm, **87% of a cached descent**, invisible to the audit because a metadata call is not a read (**ADR-35**). Removing it took a cached seek to **732 ns** and an uncached one to **5 637**, so the audit's predicted **11.6× for the cache is met** after standing at 2.13×; the same call was ~25% of a cached walk and **90% of the memo path**, which had never been measured at all. Against the C, with a new `go-skip` control: **parity or better when the work is I/O, a consistent ~1.85× when it is CPU**, and a seek costs **5.41×** a plain positioning where the C's own ratio is 5.84×. What found it was counting reads and `Length` queries rather than timing. **Closed 2026-08-27** with the decisions recorded as **ADR-36** (the cache decorates the source, one pool per engine), **ADR-37** (the three-valued policy, and why the default caches nothing), **ADR-38** (the invalidation surface, and the block that lives in two places — which contradicts `ANALYSIS.md` §9), **ADR-39** (eviction as a pure class in the reference's priority order), **ADR-40** (the project's first performance gate, at 2×, retargeted onto read counts) and **ADR-41** (the threading contract, the detector, and the library's first lock). 1333 tests at close, 566 golden. Deferred rather than written: rent-and-return with the window as the residency unit, because it describes a zero-copy design that was not built |
